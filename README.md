# Macros_VBA
- Site_Periodo_Tipo
Funciona para clasificar registros segpun los tipos de sitio de antenas, este proceso manual demoraba 4 días, con esta automatización, el proceso ahorró 3 días de trabajo.
- Enviar_RQ_PendAprob_email
Esta macro ayudó en realizar envío automático de archivos por correo outlook
- Reporte_Demora_RQ_v2
Genera el tiempo de demora entre la creación de una RQ hasta su aceptación
